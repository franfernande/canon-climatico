# Oracle en el track

Fuente: la página del [workshop de Team1](https://hub.team1.network/events/workshop-ambiente-de-desarrollo-en-la-nube-de-oracle-h7rb). Capturado el jueves 12 de noviembre de 2026, a las 9:50 (hora de Argentina).

## El workshop

**ARGENTINA SPACE! Workshop #2: Ambiente de desarrollo en la nube de ORACLE.**
Miércoles 11 de noviembre de 2026, de 11:00 a 12:30 (hora de Argentina), online.

«En la hackathon Argentina Space, Team1 LATAM presenta el track de Avalanche junto a Oracle, que suma su infraestructura cloud y participa del premio conjunto.»

## Lo que pide el sponsor

**Desafío: ambiente de desarrollo en la nube de Oracle.** «Los equipos de este track van a construir sobre Avalanche usando la infraestructura de Oracle Cloud como ambiente de desarrollo: servicios, backends y herramientas para llevar su proyecto de la idea a algo funcionando.»

Qué se obtiene:

- Acceso a infraestructura de Oracle Cloud para desarrollar y desplegar.
- Premio conjunto Avalanche × Oracle para los mejores proyectos.

**¿Qué buscamos?** «Proyectos que combinen el ecosistema Avalanche con la nube de Oracle de forma concreta: soluciones escalables, bien desplegadas y con impacto real.»

**¿Para quién es?** «Devs, builders y equipos que quieran construir en Web3 con infraestructura de nivel enterprise.»

## Cómo se relaciona con los requisitos

- El sitio del track no menciona Oracle Cloud entre los cuatro entregables ni entre los cinco criterios ([01-requisitos.md](01-requisitos.md)). Oracle aparece solo en los premios: USD 500 en créditos de Oracle para cada puesto.
- La página del workshop no aclara si usar Oracle Cloud es obligatorio o solo suma. Hay que confirmarlo con los mentores.
